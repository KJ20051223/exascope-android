ExaScope 是一个原生 Android 纯搜索客户端，无需大模型 API。

- 在设置中填写自己的 Exa API Key 和 HTTPS API 地址。
- 配置默认范围（文献 / 论文、新闻、技术文档或自定义），每次搜索自动注入查询。
- 支持分类、来源域名、查询模板、Auto / Lite 模式与结果数量设置。
- 展示标题、摘录、作者、日期和来源链接，支持取消、复制与打开原网页。
- API Key 使用 Android Keystore / AES-GCM 在本机加密保存，跟随系统深色模式。

安装：下载下方 **ExaScope-v1.0.0.apk**，支持 **Android 8.0 及以上**。SHA256SUMS.txt 用于校验文件。

范围描述影响语义相关性，严格限定来源请配合分类与域名设置。真实查询需使用自己的有效 Exa Key；本次未调用用户付费 API。

验证：19 项单元测试、4 项安卓设备测试通过；发布版 Lint 与 APK 签名验证通过。
